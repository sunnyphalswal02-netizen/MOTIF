# MOTIF — Visual Index

MOTIF is a plain HTML, CSS, and JavaScript image-search interface for finding images, places, and small details worth keeping. Its forest-green, coral, and chartreuse palette gives the index an editorial field-guide character rather than a generic gallery look. The sticky masthead keeps the identity visible while browsing, and the quick-route suggestions offer useful starting points without crowding the search area. The empty canvas and result-count line make clear where future search results will appear.
